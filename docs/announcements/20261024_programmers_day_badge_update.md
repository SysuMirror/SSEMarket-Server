# 10.24 程序员节快乐 · 集市功能更新

各位集市的小伙伴，程序员节快乐！

今天是属于每一位写代码、改 bug、也认真生活的人的日子。借着 10.24，集市上线了一批新功能，也准备了一份小小心意。

## 一、勋章系统正式上线

- **2026 程序员节限定勋章**：已自动发放到每个账号。
- **注册周年勋章**：按注册时间补发一周年、二周年、三周年纪念章；以后每年到期会自动发放，不用手动领取。
- 打开自己的**个人主页**即可看到「勋章墙」：
  - 主页默认展示全部勋章；
  - 可以自由选择展示哪几枚，也可以选择不展示；
  - 想对外展示时，可挑选 **1 枚**挂在帖子/评论的昵称旁。
- 入口：个人主页「勋章墙 → 管理」，或「我的 → 勋章墙」。

每一枚勋章都结合了集市 logo 与集市娘的蓝色蝴蝶结、小花元素，希望你会喜欢。

## 二、程序员节 10.24 币

已为每个账号发放 **10.24 币**，可在「币中心」查看流水，原因为「程序员节发放」。

同时修复并补齐了**帖子投币分成**：帖子被投币时，作者按每 1 币获得 **0.1 币**分成；历史真实投币已统一补发。

## 三、主页背景可以自己换了

个人主页顶部栏板支持上传自己的图片，并可调整**不透明度**：

- 图片会上传到图床，保存后所有访客看到一致效果；
- 不喜欢太满的图片，可以把不透明度调低，让全站背景透出来；
- 也可以随时移除图片，恢复默认渐变。

## 四、节日限定皮肤

10.24 当天全站开启程序员节限定皮肤，背景、贴纸与配色都已换上节日装。登录、注册、OAuth 授权等页面的按钮也做了适配，不会再有「按钮融入背景」的情况。
