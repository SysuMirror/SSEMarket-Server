# 邀请码（cd_keys）命名规范与批次记录

## 维护规则

**每次向 cd_keys 插入新邀请码，必须同步更新本文档的「批次记录」。**

## 表结构

库 `ssemarket` 表 `cd_keys`：

| 列 | 类型 | 说明 |
|---|---|---|
| cdkeyID | int PK AUTO_INCREMENT | 主键 |
| content | char(9) | 邀请码内容 |
| used | tinyint(1) | 0=未用 1=已用 |
| createdtime | datetime | 入库时间 |
| usedtime | datetime | 使用时间 |

## 命名规范（现行）

| 格式 | 对象 | 示例 |
|---|---|---|
| 姓名首字母缩写 + @ + 学号后四位 | 26级 | CHS@4008、GJF@4032 |
| G + 姓名首字母缩写 + 学号后四位 | 国金 | Gyzw6026、Gzy6030 |

历史遗留格式（新批次不要再沿用）：`SSE+7位随机`（2023 初期批）、`OL+8位随机`、`NEWSSE+3位`、`TCSSE/STDSSE+编号`、`SSE+日期`、`学号+姓名缩写`（如 1057hzc）等，详见下表。

## 插入方法

```bash
# 本地写好 INSERT 语句（content, used=0, createdtime=NOW()），scp 后导入
docker exec -i sse_market_db mysql -uroot -padmin ssemarket < /tmp/batch.sql
```

插入前先备份：`docker exec sse_market_db mysqldump -uroot -padmin ssemarket cd_keys > /root/cd_keys-backup-<日期>.sql`
